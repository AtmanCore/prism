# Security

PRism runs locally and promises not to write to GitHub, Jira or Confluence on its own (see
[Safety](README.md#safety)). If you find a way around that, a way to reach the local server from a
web page, or a way a reviewed PR can leak tokens or files, please report it privately through
GitHub's **Security → Report a vulnerability** on this repository rather than opening a public issue.

Please include the version (commit), how you run it (Docker or native), and steps to reproduce.
